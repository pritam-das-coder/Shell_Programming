## 📂 Repository Structure
The directory structure follows the learning progression outlined below:

* **Module 1: Introduction** - Basic scripts exploring Bourne Again Shell (Bash).
* **Module 2: Getting Started** - Foundational scripts, including "Hello, World!" and learning how to make scripts executable.
* **Module 3: Script Basics** - Implementations of variables, user input (`read`), conditional statements (`if`, `elif`), and loops (`for`, `while`).
* **Module 4: Advanced Scripting** - Complex scripts utilizing functions, arrays, file operations (reading/writing), and error handling (`set -e`).
* **Module 5: Best Practices** - Examples emphasizing code portability, security considerations, and proper documentation.
* **Module 6: Real-World Examples** - Practical administrative scripts including:
  * 🗄️ Directory backup tools using `tar`.
  * 👤 User management automation.
  * 🔍 System log monitoring utilizing `tail` and `grep`.

## 🚀 How to Run the Code
To execute any script in this repository, you must first ensure you have the correct permissions.

1. **Make the script executable:**
   ```bash
   chmod +x script_name.sh
   ```
   *This command grants the file execute permissions.*

2. **Run the script from your terminal:**
   ```bash
   ./script_name.sh
   ```
   *This tells the system to run the script located in the current directory.*
